Why HorOS?

It keeps Arch's power while rethinking setup, security, and AI integration from the ground up.

AI-native

The limon assistant is installed on every system. Choose your provider and API key after installation with limon config.

Terminal-first

A guided whiptail TUI walks you through each step, with trusted archinstall running underneath.

Pure Arch base

Standard packages, standard paths, standard pacman. No custom fork or hidden layer.

Two usage profiles

Server and Workstation. Workstation lets you choose a terminal, KDE Plasma, or GNOME.

Security by default

ufw blocks incoming connections by default. SSH is open only on the Server profile.

ISO that runs from RAM

The live environment loads into RAM with archiso and opens with the HorOS Plymouth splash; press Esc for boot details.
